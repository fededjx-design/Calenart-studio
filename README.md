📅 CalenArt Studio
Crea calendari fotografici personalizzati, gratis e direttamente nel browser — nessuna installazione, nessun account.
CalenArt Studio è un editor completo per creare calendari da 12 mesi con le tue foto, pronti per la stampa o l'export in PDF. Tutto funziona in locale nel tuo browser: le tue foto non vengono mai caricate su nessun server.
🚀 Provalo subito
👉 https://fededjx-design.github.io/Calenart-studio/
Non serve installare nulla, funziona direttamente nel browser.
✨ Funzionalità principali
📸 Caricamento foto per ogni mese, singolarmente o in blocco con "Calendario Magico" (fino a 12 foto in un colpo)
🎨 Font, colori, effetti testo (rilievo, neon, sfumature) completamente personalizzabili per mese, anno e titolo copertina
🖼️ 13 layout diversi per il collage in copertina (griglia, mosaico, polaroid, panoramico...) con forme personalizzabili
🎭 Effetti fotografici artistici veri: mosaico pixel-art, disegno a matita, schizzo a contorni, dipinto posterizzato
🗓️ Due modalità: 12 pagine mensili classiche, oppure vista annuale su pagina unica con foto o collage a tutta pagina
✨ Adesivi ed emoji personalizzabili (forma, colore, trasparenza, bordo)
🎲 Stile casuale con un click, per chi non ha voglia di scegliere ogni singolo dettaglio
🇮🇹 Festività italiane calcolate automaticamente, Pasqua e Pasquetta incluse
🌙 Fasi lunari opzionali
📤 Esporta in PDF direttamente dall'app (anche versione alta risoluzione per tipografia, con crocini di taglio)
💾 Salvataggio locale del progetto, import/export in JSON
🛠️ Tecnologie
Un unico file HTML con CSS e JavaScript puro (nessun framework, nessuna build), più due librerie via CDN (html2canvas e jsPDF) per l'esportazione PDF diretta.
